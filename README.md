## HitoHito Social App
A social media web application built for the Surge Global SE Internship Assessment (January 2025).

### Features

  User Authentication with Captcha
  Protected Post Feed with Likes
  Profile Management
  Containerized Application

### Tech Stack

  Frontend: Next.js 15, Tailwind CSS
  Backend: Node.js, Express.js, PostgreSQL, Prisma
  DevOps: Docker, GitHub Actions

### Quick Start

Clone and enter the repository:

git clone <repository-url>
cd hito-hito-social-app

Run with Docker:

docker-compose up --build


Access at:

Frontend: http://localhost:3000
Backend: http://localhost:5000

Testing
Run tests:
cd backend && npm test

Environment Variables
Copy .env to backend directory and .env.local to frontend directory.
